Website developed by Tricia Wittsack.

This website is about a hypothetical handcrafted fragrances business.
Link: [https://github.com/twittsack/Handcrafted_Fragrances](https://github.com/twittsack/Handcrafted_Fragrances)

Website created using HTML, CSS & Bootstrap components.  Images created using ChatGPT & Google AIs. Four pages have been created: Home, Fragrances, Story, Reviews.

Future improvement plans:
- Add a search capability for the products.
- Add a shopping cart & shopping ability to select products & checkout.
- Add subscription offerings.  Subscription for products & subscription to receive samples.
- Add a profile area for users to review their data and manage orders and subscriptions.



## User stories

AS A customer
I WANT TO access a description of products (What?)
SO THAT I can decide which product(s) I wish to sample (Why?)

AS A customer
I WANT TO read information about the business
SO THAT I can understand the provider of the products

AS A previous customer
I WANT TO review prior customer feedback on the business
SO THAT I can be better informed about potential purchases
